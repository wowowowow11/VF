气囊控制器 (ACM/ACU) 冲击数据处理系统

现场实施与使用操作手册 (v2.0)

一、 概述与系统功能

本系统用于气囊控制器（ACM/ACU）冲击测试数据的全自动化解包、绘图、极值计算与报告生成。使用人员只需将现场采集的原始数据按照规范放入文件夹，运行脚本即可完成以下全套工作：

1.  TXT \rightarrow JSON 解包：自动将十六进制原始数据解包为 500 点的 16 位有符号带符号物理幅值波形。
2.  JSON \rightarrow Excel 汇总：自动按 IP / 槽位分类合并，绘制 高 15cm \times 宽 30cm
    的折线对比图，并生成各 IP 第一条数据的对比汇总 Sheet 页。
3.  Excel \rightarrow Word 深度分析报告：自动扫描所有角度的数据包，计算**最高点（峰值）与最低点（谷值）**的组内均值，按
    正负 5% (\pm 5\%) 门限进行自动合格判定，生成含 高 15cm \times 宽 30cm 图表 与 30cm 对齐分析表格 的
    Word 综合汇总报告。

二、 环境准备与依赖库下载

系统基于 Python 3.8+ 环境运行。在现场电脑首次部署时，请按以下步骤安装依赖库。

1. Python 环境要求

  - 推荐版本：Python 3.8 ~ 3.11 (如 Python 3.10)

2. 一键下载安装依赖库

打开 Windows 命令行 (cmd) 或 PowerShell，执行以下命令安装所需的 Python 第三方库：

pip install pandas openpyxl python-docx matplotlib numpy

提示（国内网络加速）：若现场下载网速较慢，可以使用清华镜像源加速安装：

pip install pandas openpyxl python-docx matplotlib numpy -i https://pypi.tuna.tsinghua.edu.cn/simple

四、 文件与文件夹命名规范

为了保证系统能够自动对数据进行识别、排序和槽位映射，请现场实施人员务必遵守以下命名规范：

1. 数据子文件夹命名

  - 命名规则：以 data + 角度数字 命名（如 data15、data30、data60）。
  - 作用：脚本会自动提取文件夹中的数字 15、30 ...，并在最终 Word 报告中按角度从小到大升序自动排列。

2. 原始 TXT 数据文件命名

  - 命名规则：必须包含设备的 IP 标识，如 172.16.3.171_collect_data.txt。
  - 槽位与 IP 映射关系：
      - 1 号槽位 \rightarrow 172.16.3.171
      - 2 号槽位 \rightarrow 172.16.3.172
      - 3 号槽位 \rightarrow 172.16.3.173
      - 4 号槽位 \rightarrow 172.16.3.174

3. TXT 文本内部数据规范

  - TXT 文件每行数据需包含 ,Data: 标识及 1000 字节的十六进制串，并包含 Crash X 或 Crash Y 标识。

五、 现场操作使用步骤

操作非常简单，只需要简单 四步：

步骤 1：放入采集数据

将现场采集到的各个冲击角度的原始 txt 文件，分别放入对应角度的子文件夹（如 data15、data30 等）中。

步骤 2：打开终端/命令行

按键盘 Win + R 键，输入 cmd 回车打开命令行，进入 XY 目录：

cd /d F:\Python3.10\VF6_READCrash-v1.5\XY

(注：请将上面的路径替换为现场实际的 XY 文件夹所在路径)

步骤 3：运行自动化脚本

在命令行中直接输入以下命令并回车：

python main_process_all.py

步骤 4：查看输出结果

脚本会自动在控制台输出处理进度：

1.  自动生成 JSON：保存在各个 dataXX 文件夹内部。
2.  自动生成 Excel：在各个 dataXX 文件夹内生成 dataXX_waveform_vertical.xlsx（内含波形折线图与各 IP
    第一条数据的对比 Sheet 页）。
3.  自动生成 Word 报告：在根目录 XY 下生成最终的 冲击测试波形全角度汇总分析报告.docx。

六、 生成产物格式标准说明

最终生成的 Word 报告 (冲击测试波形全角度汇总分析报告.docx) 包含以下标准特征：

| 元素        | 标准规范                             | 说明                                              |
| :-------- | :------------------------------- | :---------------------------------------------- |
| **页面布局**  | 横向超宽页面 (35cm $\times$ 25cm)      | 保证大尺寸图表完美展示不翻页                                  |
| **对比折线图** | 高 **15 cm** $\times$ 宽 **30 cm** | 包含完整采样点刻度与物理幅值 (g)                              |
| **数据展示**  | 100% 完整显示所有通道测试值                 | 绝无 `...` 截断省略                                   |
| **分析表格**  | 总宽度精确设为 **30.0 cm** (居中)         | 与上方图表左右 1:1 对齐                                  |
| **判定规则**  | 最高点与最低点均值 **$\pm 5\%$** 区间       | 落在 $[均值 \times 95\% \sim 105\%]$ 判为【正常】，否则为【异常】 |

七、 常见问题与排查指南 (Troubleshooting)

Q1: 运行提示 PermissionError: [Errno 13] Permission denied

  - 原因：之前生成的 Excel 或 Word 报告正被 WPS 或 Microsoft Office 打开占用。
  - 解决办法：
    1.  请先在 WPS/Excel/Word 中关闭已打开的相关文件，然后重新运行脚本。
    2.  脚本自身带有防崩溃保护，若文件被占用，会自动以当前时间戳为后缀生成备份文件（如 冲击测试波形全角度汇总分析报告_180500.docx）。

Q2: 运行提示 ModuleNotFoundError: No module named 'docx' (或 pandas 等)

  - 原因：现场电脑尚未安装对应的依赖库。
  - 解决办法：重新执行第二章节的依赖安装命令：pip install pandas openpyxl python-docx matplotlib
    numpy。

Q3: 图片中的中文显示为方块或乱码

  - 原因：系统缺少默认的中文黑体/微软雅黑字体。
  - 解决办法：Windows 系统通常自带微软雅黑，若出现乱码，请确认系统中是否删除了默认字体。
